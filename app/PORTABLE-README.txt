Mustek Studio Portable — Windows 10 x64

Запуск: MustekStudio-Portable.exe.
Для переноса программы на другой компьютер достаточно скопировать этот EXE.
Он содержит интерфейс, PDFsharp, модуль SANE GT68xx, USB-библиотеки и прошивку.
Программа работает без Python, Visual Studio, интернета и установки приложения.
Используется .NET Framework, входящий в состав Windows 10.

При первом запуске рядом с EXE создаётся MustekStudio.Data:
  app-data — настройки, рабочие страницы и журналы;
  scans — папка сохранения по умолчанию;
  engine — встроенные служебные файлы, лицензии и исходники.
Папка, из которой запускается EXE, должна быть доступна для записи.
Чтобы перенести настройки и документы, скопируйте EXE вместе с MustekStudio.Data.
Обновляя программу, заменяйте EXE и сохраняйте существующую папку данных.

Подключение: Mustek 1200 UB Plus, USB VID 05D8 PID 4002.
На компьютере должен быть установлен WinUSB для этого сканера.
На текущем компьютере он уже установлен. При подключении к другому компьютеру
его нужно настроить один раз, например через официальный Zadig:
https://zadig.akeo.ie/
Установка системного USB-драйвера выполняется отдельно с правами администратора.
Обычная работа Mustek Studio повышения прав не требует.

Работа:
1. Положите лист на стекло и выберите DPI предпросмотра.
2. Нажмите «Предпросмотр».
3. Выберите DPI сканирования и нажмите «Сканировать страницу».
4. Для многостраничного документа заменяйте лист и добавляйте новые страницы.
5. Выберите PDF + Все страницы и сохраните один PDF либо PNG для отдельных файлов.
6. В «Настройки…» можно выбрать русский/английский язык и светлую/тёмную тему.

Разрешения: 50, 75, 150, 300, 600, 1200 dpi. Более высокое DPI требует больше
времени и памяти. В тёмной теме кнопки и индикатор фиолетовые.
Рабочие страницы восстанавливаются после закрытия приложения.

Контроль сборки: --portable-check. Проверка подключённого сканера без
считывания страницы: --portable-check --probe-scanner.
Отчёт: MustekStudio.Data\portable-check.txt.
