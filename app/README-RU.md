# Mustek Studio

Приложение для Mustek 1200 UB Plus под Windows 10 x64.

## Запуск

Откройте `Start-Scanner.cmd` в основной папке проекта либо
`app\MustekStudio.exe`. Программа использует установленный WinUSB и уже
проверенный модуль сканирования. Python и права администратора для работы
приложения не нужны.

Если окно было открыто во время разработки, закройте его и запустите снова,
чтобы загрузить окончательную сборку.

## Язык и тема

Нажмите **Настройки…** в правом верхнем углу окна. Выберите **Русский**
или **English**, затем **Светлая / Light** либо **Тёмная / Dark** и нажмите
**Сохранить / Save**. Выбор применяется к открытому документу без перезапуска
и восстанавливается при следующем запуске.

В тёмной теме основные кнопки фиолетовые; фон, списки и область просмотра
также затемняются. Цвета отсканированного изображения сохраняются.
Кнопка **Отмена / Cancel** оставляет прежние настройки приложения.

## Предпросмотр

1. Положите документ лицевой стороной к стеклу и закройте крышку.
2. Выберите **Разрешение предпросмотра**. Для начала удобно 75 dpi.
3. Нажмите **Предпросмотр**. Дождитесь появления изображения.
4. Колесо мыши и кнопки `+`/`−` меняют масштаб просмотра; перетаскивание
   перемещает изображение. **Вписать** показывает лист целиком,
   **100%** отображает один пиксель изображения одним пикселем экрана.

Изменение масштаба не меняет DPI. Предпросмотр не входит в список страниц
и не сохраняется в итоговый документ. Для другого качества предпросмотра
выберите другое DPI и выполните его заново.

## Сканирование страниц

1. Выберите **Разрешение сканирования** и цветовой режим.
2. Нажмите **Сканировать страницу**. Страница появится в нижней ленте.
3. Замените лист и снова нажмите **Сканировать страницу**.
4. В ленте выбирайте страницы; **Раньше/Позже** меняют порядок,
   **Повернуть 90°** меняет ориентацию, **Убрать** исключает страницу
   из документа, сохраняя её рабочую копию и исходный импортированный файл.

Разрешения: 50, 75, 150, 300, 600 и 1200 dpi. Цветной режим и оттенки серого,
8 бит на канал. Большие значения DPI требуют больше времени и памяти.
Доступность значений определяется модулем GT68xx; аппаратно проверены
предпросмотр 75 dpi и цветное сканирование 150 dpi.

Для сборки готовых изображений используйте **Добавить изображения…**
или перетащите PNG, JPEG, BMP в область просмотра. Порядок можно изменить
после импорта. Поворот и экспорт не изменяют исходные файлы.

## PNG и PDF

- **PDF + Все страницы**: один многостраничный PDF в порядке нижней ленты.
- **PDF + Выбранная страница**: PDF только с выделенной страницей.
- **PNG + Все страницы**: отдельный PNG для каждой страницы; при нескольких
  страницах программа предложит выбрать папку.
- **PNG + Выбранная страница**: один PNG.

Для PDF можно выбрать A4 с полями 5 мм или физический размер скана,
вычисляемый по DPI. На A4 изображение целиком вписывается в страницу.
Для повёрнутых альбомных страниц ориентация A4 меняется автоматически.
Изображения в PDF сохраняются без дополнительного JPEG-сжатия; OCR
и текстовый слой в этой версии не выполняются.

Нажмите **Сохранить PDF…** или **Сохранить PNG…** и выберите назначение.
Запись выполняется через временный файл: незавершённый экспорт не заменяет
существующий документ. Кнопка **Открыть папку сканов** открывает последнюю
папку сохранения; до первого экспорта это `scans` в папке проекта.

## Сохранение рабочего документа

Список страниц и настройки восстанавливаются при следующем запуске.
Рабочие PNG находятся в `app-data\pages`, список — `app-data\document.xml`.
Не удаляйте папку `app-data`, если хотите продолжить документ позже.
Чтобы собирать следующий документ, уберите предыдущие страницы из ленты.
Удалённые из ленты рабочие копии остаются в `pages` для восстановления.

Во время работы сканера изменение документа и повторный запуск сканирования
заблокированы. При закрытии окна программа попросит дождаться завершения
текущей операции.

## Сборка и проверки

Исходники: `ScannerCore.cs`, `MustekStudio.cs`, `Appearance.cs`.

`build.ps1` собирает x64 WinForms-приложение компилятором .NET Framework,
поставляемым с Windows. Visual Studio и .NET SDK не требуются.
Рядом с EXE должна находиться `PdfSharp.dll`. Основные папки `runtime`
и `firmware` должны оставаться рядом с папкой `app`.

`test.ps1` проверяет импорт, перестановку, поворот, восстановление документа,
сохранность оригиналов, PNG/DPI, многостраничные PDF и защиту существующего
файла при ошибке экспорта. Рабочие результаты находятся в `app-tests`.
`Hardware-Test.ps1` выполняет настоящий цветной скан 150 dpi.
`test-appearance.ps1` проверяет все четыре сочетания языка и темы,
сохранение и восстановление выбора, отмену настроек, переводы, цвет кнопок
и сохранность документа и масштаба при переключении. Изображения интерфейса
для проверки находятся в `app-tests\appearance-final`.
Журналы обычных сканирований: `app-data\logs`.

Тестовые PDF проверены независимым PDF-парсером и отрисовкой PDFium:
число и порядок страниц, ориентация и физические размеры подтверждены.
