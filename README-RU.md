# Mustek Studio

[Русская инструкция](README-RU.md) · [English instructions](README.md)

Приложение для сканера **Mustek ScanExpress 1200 UB Plus**, USB ID
**05D8:4002**, под **Windows 10 x64**. Другие модели с таким же USB ID
не проверялись.

## Скачать и установить

1. Скачайте [MustekStudio-Setup.exe](release/MustekStudio-Setup.exe).
   На странице файла в GitHub нажмите **Download raw file**.
2. Запустите установщик. Выберите русский или английский язык и папку,
   доступную вашей учётной записи для записи. Папка по умолчанию:
   `%LOCALAPPDATA%\Programs\MustekStudio`.
3. При необходимости создайте ярлык на рабочем столе. В конце оставьте
   включённым **Завершить настройку сканера и открыть Mustek Studio**.
4. Если появился помощник подключения, подключите сканер к USB и питанию.
   Нажмите **Настроить WinUSB** и подтвердите запрос Windows.
5. Во встроенном Zadig выберите сканер с **USB ID 05D8:4002**. Если его
   не видно, включите **Options → List All Devices**. Справа выберите
   **WinUSB**, затем нажмите **Install Driver** или **Replace Driver**.
6. После успешной установки откройте Mustek Studio. Помощник подключения
   также доступен в меню «Пуск», в группе Mustek Studio.

Установка приложения не требует прав администратора. Для привязки WinUSB
потребуется отдельное подтверждение администратора. Установщик включает
Zadig и компоненты сканирования, работает без интернета. Для использования
программы Python и Visual Studio не нужны.

Проверить контрольную сумму установщика можно в PowerShell:

```powershell
Get-FileHash .\MustekStudio-Setup.exe -Algorithm SHA256
```

Сравните результат с [release/Setup-SHA256.txt](release/Setup-SHA256.txt).

## Предпросмотр и сканирование

1. Положите документ лицевой стороной к стеклу и закройте крышку.
2. Выберите **Разрешение предпросмотра** и нажмите **Предпросмотр**.
   Предпросмотр не добавляется в документ. Колесо мыши, **+**, **−**,
   **100%** и **Вписать** меняют масштаб отображения, а не DPI сканирования.
3. Выберите **Разрешение сканирования** и **Цветовой режим**, затем
   нажмите **Сканировать страницу**.
4. Замените лист и повторите сканирование, чтобы добавить следующую
   страницу. В нижней ленте можно выбирать, переставлять, поворачивать
   и убирать страницы.
5. Выберите **PDF**, **Все страницы** и нажмите **Сохранить PDF…**,
   чтобы получить один многостраничный документ. Пункт **Выбранная
   страница** сохраняет только выделенную страницу.
6. Выберите **PNG** для сохранения отдельных изображений. Готовые PNG,
   JPEG и BMP можно добавить кнопкой **Добавить изображения…** или
   перетащить в окно.

Доступные значения DPI: 50, 75, 150, 300, 600 и 1200. Высокое разрешение
требует больше времени и памяти. Ранее на устройстве проверялись
предпросмотр 75 dpi и цветной скан 150 dpi; наличие пункта в меню не
означает, что каждый режим проверен аппаратно. Для PDF доступны размер
исходного скана и A4 с полями 5 мм. Распознавания текста OCR нет.

## Язык, тема и сохранение работы

Нажмите **Настройки…** справа вверху. Доступны русский и английский языки,
светлая и тёмная темы. Настройки применяются без перезапуска. В тёмной
теме основные кнопки фиолетовые. Цвета самого скана сохраняются.

Полупрозрачная подпись справа внизу переводится вместе с интерфейсом:
`@Навайбкодил 5U5L1K` / `@Vibe-coded by 5U5L1K`.

Установленная программа сохраняет рабочий документ, изображения страниц,
настройки и журналы в `MustekStudio.Data` рядом с `MustekStudio.exe`.
Обновление и удаление программы сохраняют эту папку. Для резервной копии
сохраните её и экспортированные документы. Перед началом отдельного
документа уберите прежние страницы из ленты. Удаление из ленты не удаляет
рабочую копию изображения.

Если сканер не найден, проверьте питание, USB и привязку WinUSB к
05D8:4002, затем нажмите **Проверить сканер**. При необходимости снова
откройте помощник подключения. Незавершённый скан или экспорт выдаёт ошибку.

## Состав исходников

- `app/`: приложение C# WinForms, переводы, темы, иконка, скрипты сборки
  и существующие тесты.
- `setup/`: сценарий Inno Setup, помощник подключения и тексты установки.
- `patches/`, `fix_*.py`, `*-fix.json`: исправления SANE и их контрольные суммы.
- `downloads/backends-1.4.0.tar.bz2`: архив исходников SANE.
- `release/`: установщик и его SHA256.
- `Restore-Dependencies.ps1`: восстановление зависимостей сборки из
  установленной копии приложения без добавления DLL в репозиторий.

В ветке нет отдельных портативных и отладочных EXE, результатов
сканирования, профилей пользователя, журналов и распакованных бинарных
зависимостей. Установщик содержит приложение, которое он устанавливает.

## Сборка из исходников

Нужны Windows x64, Windows PowerShell 5.1 и компилятор C# из .NET Framework,
входящего в Windows 10. Для сборки портативного пакета нужен Python 3.
Нативные зависимости восстанавливаются из приложенного установщика;
этот способ не пересобирает SANE из исходников на C.

1. Установите приложенный setup. Выполнять сканирование не требуется.
2. Откройте **Windows PowerShell** в корне копии исходников:

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Restore-Dependencies.ps1
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\app\build.ps1
   ```

   Если программа установлена в другую папку, передайте скрипту восстановления
   параметр `-InstalledExe 'D:\Apps\MustekStudio\MustekStudio.exe'`.
   Обычная сборка запускается через `Start-Scanner.cmd`.
3. Для сборки портативной версии добавьте `python.exe` в PATH и выполните:

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\app\Build-Portable.ps1
   ```

4. Для пересборки setup поместите компилятор Inno Setup 7 и его файлы
   в `tools\InnoSetup7` — внутри должен находиться `ISCC.exe`. Затем выполните:

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup\Build-Setup.ps1
   ```

   Восстановленный Zadig проверяется по хешу и цифровой подписи.
   Сначала собирайте portable: именно его EXE входит в setup.

Существующие `app/test.ps1` и `app/test-appearance.ps1` создают тестовые
документы и проверяют поведение программы. Аппаратные тесты выполняют
настоящее сканирование и требуют подключённого сканера. Новые сборки и
восстановленные зависимости исключены через `.gitignore`.

Уведомления о сторонних компонентах: [THIRD-PARTY.md](THIRD-PARTY.md).
